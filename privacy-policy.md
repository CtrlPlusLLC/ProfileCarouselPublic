# Privacy Policy for Profile Carousel

Last updated: 2026-01-18

This Privacy Policy describes how the Profile Carousel Chrome extension ("Extension") collects and uses information.

## What data the Extension collects

- LinkedIn profile data that you view while the Extension is active (name, title, company, location, profile URL, and profile photo when available).
- Optional contact data when you link Google Contacts or HubSpot (only for the contact(s) you link).
- Extension configuration and UI preferences (stored in Chrome storage).

## How data is used

- To display and manage the tracked profiles list inside the Extension.
- To sync tracked profiles to your configured Firebase/Firestore project.
- To optionally link and update Google Contacts or HubSpot records when you enable those features.

## Where data is stored

- Profile data is stored in your Firebase/Firestore project that you configure in the Extension options.
- UI preferences and local caches are stored in Chrome storage.

## Data sharing

- The Extension does not sell or share data with third parties outside of the services you configure (Firebase/Firestore, Google Contacts, HubSpot).
- Data is only sent to those services to support the Extension’s features.

## User controls

- You control which Firebase project the Extension uses via the options page.
- You can delete tracked profiles using the Extension UI.
- You can uninstall the Extension at any time to stop all data collection.

## Security

- Access to Firebase data depends on your Firestore security rules and authentication settings.
- You should restrict Firebase access to your organization to prevent unauthorized use.

## Contact

For questions about this policy, contact your administrator or the team that provided the Extension.
